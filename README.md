# Youtube Player Replacer By Iframe Installation Guide

This guide will walk you through the steps to download, extract, and install this Chrome extension manually.

## 📥 Download the Extension

1. Click the green **"Code"** button on the top-right of the repository.
2. Select **"Download ZIP"**.

   Alternatively, you can use this direct link:  
   `https://github.com/liy1414/youtube-player-replacer-by-iframe/archive/refs/heads/master.zip`

## 📂 Extract the Folder

1. After downloading the ZIP file, extract it to a location of your choice.
2. You should now have a folder named something like `youtube-player-replacer-by-iframe-master`.

## 🧩 Install the Extension in Chrome

1. Open Google Chrome.
2. In the address bar, go to:  
   `chrome://extensions`
3. Turn on **Developer mode** (top right corner).
4. Click **Load unpacked**.
5. Select the folder you just extracted.

✅ The extension should now be installed and visible in your Chrome extensions bar.
